# Apex Racing Manager

A motorsport career-management game built with Godot, using Automobilista 2 (AMS2) as its data and live-telemetry source.

## Releases

Download the latest build from the [Releases](https://github.com/DatGuyMangoes27/Apex-Racing-Manager/releases) page.

### v0.1
First public alpha. Windows build (see release assets).

> Alpha software - expect rough edges. AMS2 is required for live race-weekend telemetry.
